# `rig` module group

The rig: the setup of tracks a performer plays, one per instrument.

| Module | Description | Root package |
| ------ | ----------- | ------------ |
| [`rig`](rig/docs/ARCHITECTURE.md) | Tracks, which route MIDI from an input to an output through a tuner, and the rig session behind a thread-safe service | `org.calinburloiu.music.microtonalist.rig` |

See the [module overview](../docs/architecture/module-overview.md) for the other groups and how their modules depend
on each other.
