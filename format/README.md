# `format` module group

File I/O of the persistable domain objects, mostly as JSON.

| Module | Description | Root package |
| ------ | ----------- | ------------ |
| [`format`](format/docs/ARCHITECTURE.md) | Reads compositions, scales and rigs from local files, HTTP(S) and the user's library | `org.calinburloiu.music.microtonalist.format` |

See the [module overview](../docs/architecture/module-overview.md) for the other groups and how their modules depend
on each other.
