# `ui` module group

The desktop GUI, a thin presentation layer over the tuning state.

| Module | Description | Root package |
| ------ | ----------- | ------------ |
| [`ui`](ui/docs/ARCHITECTURE.md) | A Swing window that lists the composition's tunings and switches the current one | `org.calinburloiu.music.microtonalist.ui` |

See the [module overview](../docs/architecture/module-overview.md) for the other groups and how their modules depend
on each other.
